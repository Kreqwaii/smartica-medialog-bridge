# Коннектор МИС «Медиалог» ↔ Smartica.ai

Интерактивный прототип и локальный мост-коннектор для интеграции МИС «Медиалог» с голосовым ассистентом врача Smartica.ai.

## Возможности
- **Запуск сессии Smartica.ai** из карточки приёма («Медиалог») с передачей контекста пациента и врача.
- **Симуляция диктовки и опроса готовности** (`GET /status` / polling) с автоматическим заполнением полей осмотра (`Жалобы`, `Анамнез`, `Объективный статус`, `Диагноз`).
- **Модальное окно подсказок и назначений** (Smartica Suggestions) с выбором рекомендованных услуг и добавлением в лист назначений.
- **Фиксация и сохранение в МИС «Медиалог»** с полным журналом HTTP-взаимодействий (`#httpLogList`).

## Структура проекта
- `index.html`, `styles.css`, `app.js` — статический фронтенд (работает без сборки и может быть развёрнут на GitHub Pages).
- `backend/` — серверная часть локального моста-коннектора.

## Локальный запуск
```bash
py -m http.server 8792 --bind 127.0.0.1
```
Откройте `http://127.0.0.1:8792/` в браузере.
